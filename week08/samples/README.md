# Week 8 Sample Images

These are backups for the lab, not the lab itself. Use your own images whenever you can.

You don't need to copy anything. When a script can't find one of your `my_` files in the `week08` folder, it uses the matching sample here and prints a note saying so. As soon as you save your own file (for example `my_pile25.jpg`), the script uses yours instead.

If you use a sample for any task, say so in `lab8_results.txt`.

| Sample | Stands in for | What it is |
|---|---|---|
| `unusual.jpg` | `my_unusual.jpg` | A mandrill. The chapter's small model called it a gorilla. |
| `photo1.jpg` | `my_photo1.jpg` | The chained library at Hereford Cathedral, from an old postcard |
| `photo2.jpg` | `my_photo2.jpg` | A chess set |
| `pile3.jpg`, `pile12.jpg`, `pile25.jpg` | `my_pile3.jpg`, `my_pile12.jpg`, `my_pile25.jpg` | Drawn coins on a wood table: exactly 3, 12, and 25. Some in the big pile overlap. |
| `error_small.png`, `error_big.png` | `my_error_small.png`, `my_error_big.png` | `broken.py`'s real traceback in an Ubuntu terminal, at normal size and zoomed in |
| `sketch.jpg`, `notes.jpg` | `my_sketch.jpg`, `my_notes.jpg` | For the optional two-image demo: an app sketch and its feature list |
| `memo.wav` | `my_memo.wav` | For the optional listening demo: a short spoken reminder (computer voice) |

The drawn coins are cleaner than a real photo, so a real pile is usually *harder* for the model to count.
